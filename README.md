# John Angelo P. Cabatingan — Digital Portfolio

Personal digital portfolio website for **John Angelo P. Cabatingan**, Networking Specialist & Full-Stack Software Developer | BSIT Student.

Connected to GitHub: [@brets60](https://github.com/brets60)

## Tech Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS 3
- **Icons:** Lucide React & Custom SVG
- **Animations:** Subtle CSS Keyframes & Micro-interactions

## Features
- **Authentic Portrait & Hero Section**: Studio portrait, live availability indicator, and GitHub connectivity.
- **Tools I Work With**: Categorized skills spanning Networking & Systems, Frontend, Backend, Databases, Tools, and IoT.
- **GitHub Repositories Showcase**: Connected directly to `@brets60` showcasing active systems and repositories.
- **Experience Timeline**: Capstone milestones, field networking support, and collegiate progression.
- **How I Build**: 4-phase methodology (`Understand` → `Plan` → `Build` → `Improve`).
- **Education & Faculty References**: Torres Capitol College BSIT degree details and verified faculty citations.
- **Interactive Contact & Resume**: Printable CV modal and direct contact channels.

## Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```

## Push to GitHub
```powershell
.\deploy-to-github.ps1
```
